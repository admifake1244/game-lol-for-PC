Thanks for downloading!
gamelol is for PC/laptop, gamelol2 is for mobile.

HOW TO PLAY ON PC/LAPTOP(mac/windows):
WINDOWS:
--- STEP 1: DOWNLOAD PYTHON (Paste this link into your web browser and download) ---
=>"https://python.org"
(Installation note: You MUST check the "Add python.exe to PATH" box, then click Install Now)

--- STEP 2: OPEN COMMAND PROMPT / CMD (Press Windows + R, paste this word, and press Enter) ---
=>"cmd"

--- STEP 3: CHECK PYTHON & UPDATE PIP (Paste each line into CMD and press Enter) ---
=>"python --version"
=> "python -m pip install --upgrade pip"

--- STEP 4: INSTALL PYGAME (Paste into CMD, press Enter, and wait for it to finish) ---
=>"pip install pygame"

--- STEP 5: PLAY GAME (Copy code from gamelol1, paste into CMD and press Enter) ---

MAC:
--- STEP 1: DOWNLOAD PYTHON FOR MAC (Paste this link into Safari/Chrome and download) ---
=>"https://python.org"
(Open the downloaded .pkg file and keep clicking Continue/Agree to complete the installation)


--- STEP 2: OPEN TERMINAL (Press Command + Space, type this word, and press Enter) ---
=> "Terminal"


--- STEP 3: CHECK PYTHON & UPDATE PIP (Paste each line into Terminal and press Enter) ---
=>"python3 --version"
=>"python3 -m pip install --upgrade pip"


--- STEP 4: INSTALL PYGAME (Paste into Terminal, press Enter, and wait for it to finish) ---
=>"pip3 install pygame"


--- STEP 5: PLAY GAME (Copy code from gamelol1, paste into Terminal and press Enter) ---

HOW TO PLAY ON MOBILE:
1. Open the link: https://onecompiler.com/pygame
2. Copy the code from gamelol2.py or here: https://github.com/admifake1244/game-lol-for-PC/blob/main/gamelol2.py
3. Delete all the sample code and paste in the new code.
4. Tap Play (the blue button) to play the game!
